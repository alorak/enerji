# enerji

Tek sayfalık, etkileşimli enerji eğitimi.

## İçerik

- Fizik/felsefe: enerji nedir, “kaynak” ne demektir, neden korunur?
- Enerjinin tanımı, birimleri ve enerji bilançosu
- Zamana göre değişim: `P = dE/dt`
- 1B / 2B / 3B enerji dağılımı ve enerji yoğunluğu
- Yerel enerji korunumu ve enerji akısı
- Klasik mekanik: iş, güç, kinetik/potansiyel enerji, sürtünme
- Elektromanyetik enerji yoğunluğu, Poynting vektörü ve Poynting teoremi
- Foton–madde etkileşimleri: fotoelektrik olay, Compton saçılması, çift oluşumu ve enerji eşikleri
- “Enerjiyi ne değiştirir?” özeti
- Dört etkileşimli simülasyon:
  - enerji bilançosu
  - 2B potansiyel enerji manzarası
  - yay–kütle–sönüm sistemi
  - vakumda düzlem elektromanyetik dalga
  - foton enerji tarayıcısı: fotoelektrik, Compton ve çift oluşumu kinematiği

## Çalıştırma

Herhangi bir build adımı yoktur. `index.html` doğrudan tarayıcıda açılabilir veya GitHub Pages ile yayınlanabilir.

Simülasyonlar eğitim amaçlıdır. Mekanik örneklerde sayısal integrasyon kullanıldığı için çok küçük sayısal sapmalar görülebilir.
